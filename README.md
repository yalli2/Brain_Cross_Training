# Brain Cross Training

HR 성인 대상 뇌훈련 프로그램의 챕터별 인터랙티브 사이트입니다. 12개 챕터마다 활동 하나를 제출하면, 같은 그룹 코드를 입력한 참가자들의 결과가 실시간으로 차트에 모입니다.

`index.html` 한 파일로 동작합니다.

## 그룹 코드 공유

- 화면 위쪽에 닉네임과 그룹 코드를 입력합니다. 같은 코드를 입력한 사람끼리만 결과가 보입니다. 대소문자와 앞뒤 공백은 구분하지 않습니다.
- 그룹 코드는 비밀번호가 아니라 방 이름입니다. 코드를 아는 사람은 그 그룹의 응답을 볼 수 있으므로 개인 정보는 입력하지 마세요.

## GitHub Pages에서 실시간 공유 켜기

Claude 아티팩트 링크로 열면 별도 설정 없이 공유됩니다. GitHub Pages로 열 때는 아래 설정이 필요합니다.

1. Firebase 콘솔에서 프로젝트를 만들고 Realtime Database를 생성합니다.
2. Rules 탭에 아래 내용을 붙여 넣고 게시합니다.

```json
{ "rules": { "r": { "$group": { ".read": true, ".write": true } } } }
```

3. 데이터베이스 주소(예: `https://프로젝트이름-default-rtdb.firebaseio.com`)를 `index.html` 안의 `CONFIG.firebaseUrl`에 입력하고 저장합니다.

위 규칙은 누구나 읽고 쓸 수 있으므로 교육용 익명 응답에만 사용하세요. 주소를 입력하지 않으면 내 응답만 보이는 로컬 모드로 동작합니다.
